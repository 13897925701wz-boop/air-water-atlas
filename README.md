# 凝水于空 · 空气取水潜力可视化平台

中国空气取水潜力评估与选址可视化项目，版本 v1.1。

## 下载与使用

- `air-water-atlas-v1.1-source.zip`：完整源码及气象数据。下载并解压后，按其中 README 启动。
- `凝水于空-双击打开.html`：免安装离线版。点击文件后选择 Download raw file 下载，双击用浏览器打开。

源码采用 Vue 3、Vite、Pinia 和 ECharts。覆盖 31 个省会及吉林 9 个市州采样点，使用 NASA POWER 2021—2025 年数据。支持全国总览、省份详情、多省对比、季节趋势、参数模拟、CSV 与分析报告导出。

评分为探索性气象适宜性指标，未经装置实测校准，不代表实际产水量、成本或投资回报。

此仓库用于保存和下载项目文件，尚未部署在线网站。
